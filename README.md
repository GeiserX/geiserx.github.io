# geiserx.github.io

This user site only redirects to [cv.geiser.cloud](https://cv.geiser.cloud/), where the page and CV live (repository [GeiserX/cv](https://github.com/GeiserX/cv)).

It exists so that old links to geiserx.github.io keep working, and so that no custom domain sits on the user site: a custom domain here would be applied to every project site under geiserx.github.io/<repo>/ as well.
