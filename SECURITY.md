# Security Policy

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Report it privately through GitHub: https://github.com/GeiserX/geiserx.github.io/security/advisories/new

You will get an answer within 72 hours. Include what you found, how to reproduce it, and the version or commit you tested.

## Supported versions

This repo has no releases. Only the `main` branch, which GitHub Pages serves, receives security fixes.
